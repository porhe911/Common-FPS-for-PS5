# Common FPS for PS5 v1.2.3 RC9

RC9 исправляет выбор цвета и управление настройками после проверки RC8 на
FW 11.60. Пользователь подтвердил, что ярлык «Мультимедиа → Common FPS» появился
и работает, но сообщил о зависании игры после смены цвета и положения.

## Изменения

- Кнопка цвета открывает палитру из восьми подписанных цветов. Цвет выбирается
  явно; открытие палитры не меняет настройку. Произвольный HEX сохранён.
- ✕ активирует выбранную крестовиной кнопку. Учтены стандартные объекты
  GamepadButton, старые числовые кнопки WebKit, legacy keyCode и известный
  порядок лицевых кнопок Sony без стандартного mapping.
- Нативный щелчок браузера под неподвижным курсором теперь использует выбранную
  крестовиной кнопку. Дубли Gamepad/Enter/click от одного нажатия объединяются.
- Поля HEX исключены из навигации крестовиной, чтобы фокус не застревал в поле
  редактирования. Их можно выбрать курсором. OPTIONS сохраняет настройки.
- Начальные цвета/шрифт задаются сразу при создании виджетов. Повторное
  назначение тех же стилей в том же обновлении удалено.
- Шрифт переустанавливается только при изменении размера. Изменение цвета или
  угла не создаёт новый UIFont. Обычный отсчёт FPS обновляет только текст.
- Временные UIFont/UIColor, строки и новые Label закрепляются GC handles до
  завершения вызовов; указатель на unboxed-значение не переживает владельца.
- Отслеживается замена RootWidget внутри прежней Scene. Дочерние виджеты из
  старого корня освобождаются; новый корень получает собственные виджеты.
- Убраны новые фоновые вызовы Width/Height из RC8. Для проверки стабильности
  используется известная логическая сетка RC7 — 1920×1080. Размер и отступы
  сохраняются. Альтернативные размеры самой PUI-сцены аппаратно не проверены.
- В логе контроллера фиксируется успешное сохранение параметров. В логе
  ShellUI — начало/окончание применения стиля. Оба лога по-прежнему сбрасываются
  при активации и ограничены 64 КиБ каждый.

## Обновление и проверка

1. **Перезагрузите PS5**, чтобы выгрузился рендерер RC8. Запустите один ELF
   либо plugin RC9 привычным работающим загрузчиком.
2. Откройте «Мультимедиа → Common FPS». Внизу страницы должна быть версия RC9.
3. Откройте палитру, выберите цвет, задайте угол. Выберите «Сохранить»
   крестовиной и нажмите ✕ либо OPTIONS. Дождитесь сообщения «Сохранено».
4. Откройте ярлык заново: цвет и угол должны сохраниться. Затем запустите игру.

Настройки RC8 сохраняются; удалять конфигурацию не нужно. Измерение FPS,
фильтр RC7, инъекция и защищённая запись guard-byte не изменялись.

## Границы проверки

В `CommonFPS(5).log` успешно завершены регистрация ярлыка, восстановление auth,
bootstrap и запись guard-byte. Сам контроллер продолжал работу и наблюдал
несколько game PID. Этот лог не содержит стека зависания и не доказывает его
причину. Исправлены найденные риски в новых UI-операциях; устранение зависания
ещё нужно подтвердить на консоли.

При повторении нужны оба файла: `/data/CommonFPS.log` и
`/data/CommonFPS_shellui.log`, а также игра и момент зависания.
Программные проверки и модель сборщика мусора не заменяют тест на PS5.
