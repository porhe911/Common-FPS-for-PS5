# Common FPS for PS5 v1.2.3 RC8

Пользователь подтвердил идеальную работу RC7 на FW 11.60. RC8 добавляет
настройки внешнего вида; измерение FPS, фильтр RC7 и проверенный путь инъекции
и записи guard-byte сохранены.

## Что добавлено

- Ярлык **Common FPS** в разделе **Мультимедиа**. При активации проверяется
  регистрация собственного title ID `CFPS00060`; отсутствующий ярлык создаётся
  через AppInstUtil, аналогично принципу ShadowMount+.
- Встроенная страница `http://127.0.0.1:39029/`, доступная только на PS5.
  Интернет, ПК и отдельный веб-сервер для настроек не нужны.
- Четыре угла; размер 14–64; отступы по X/Y; скрытие `FPS:`; отдельные цвета
  подписи и цифр. Палитра и ввод произвольного цвета `#RRGGBB`.
- Предпросмотр, кнопка сохранения и возврат к исходным значениям. Кнопки
  доступны с курсора, клавиатуры и через стандартные события Gamepad API.
- После сохранения изменения приходят в существующие виджеты на следующем
  секундном обновлении. Новая инъекция для изменения настроек не требуется.
- Настройки сохраняются в `/data/CommonFPS/config.ini` через временный файл,
  fsync и rename. При ошибке сохранения активная конфигурация не изменяется.
- Привязка к размеру корневой PUI-сцены, масштабирование шрифта и отступов.
  При отсутствии размеров используется прежняя система координат 1920×1080.
  Диагональ телевизора не требует отдельного профиля. При обрезании краёв
  телевизором увеличьте отступы.

## Установка

1. Перед переходом с RC7 **перезагрузите PS5**, чтобы обновился и встроенный
   ShellUI-рендерер: IPC изменён на v2, старые/новые компоненты не смешиваются.
2. Запустите **один** файл: `Common_FPS_PS5_v1.2.3.elf` либо etaHEN plugin.
   Используйте уже работающий у вас загрузчик.
3. Откройте **Мультимедиа → Common FPS**, измените параметры и нажмите
   **Сохранить**. Затем вернитесь в игру кнопкой PS.
4. Настройки переживают перезагрузку. Сам счётчик по-прежнему нужно запускать
   после загрузки jailbreak-среды; ярлык открывает настройки работающего ELF.

Исходный вид совпадает с RC7: слева снизу, размер 22, отступы 10/4,
фиолетовая подпись, белые цифры. Логи `/data/CommonFPS.log` и
`/data/CommonFPS_shellui.log` перезаписываются при активации; максимум 64 КиБ
каждый. Настройки сохраняются отдельно от логов.

## Границы проверки

Новый ярлык и свойства PUI требуют проверки на настоящей PS5, включая
конкретный браузер и управление DualSense. Подтверждение идеальной работы RC7
не является аппаратным подтверждением RC8 или всех режимов HDMI.
При отсутствии размеров сцены безопасно сохраняется прежняя координатная база.
Создание ярлыка пропускается на FW 12+: прямой AppInstUtil-путь на этих
прошивках отличается; патчи ShellCore не добавлялись.

Если ярлыка нет, нужен `/data/CommonFPS.log`: строка `Media launcher` показывает
init/check/install/present/auth_restored. Если страница открывается, но стиль
не меняется, приложите также `/data/CommonFPS_shellui.log`. Не запускайте RC7
и RC8 одновременно.
