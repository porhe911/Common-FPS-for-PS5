# Common FPS for PS5 v1.2.3 RC5

Лог RC4 на FW 11.60 подтвердил, что резервное чтение кода ShellUI работает:
`read_primary_rc=14 read_fallback_rc=0`, probe завершён успешно. Следующий
этап останавливается на записи одного байта проверки потока:
`phase=guard write_rc=14 verified=0 restored=1`. Поэтому renderer ещё не
дошёл до отрисовки FPS.

RC5 заменяет запись этого байта на FW 11.60 на проверяемую MDBG-запись с
временным разрешением записи в содержащую его JIT-область. Контроллер
останавливает ShellUI, сверяет 16 исходных байтов, сохраняет точные флаги
защиты VM entry, разрешает запись, записывает один байт и восстанавливает
исходные флаги. Восстановление проверяется до продолжения ShellUI.
Результат MDBG проверяется по syscall, статусу ответа и количеству байтов;
после этого отдельно сверяется полный блок кода.

При ошибке код откатывается с использованием сохранённых первоначальных
флагов. Неизменившийся код сам по себе не считается полным восстановлением,
если защита памяти не восстановлена. SDK меняет защиту содержащего VM entry,
а не выделенной аппаратной страницы. Временные auth/caps контроллера
восстанавливаются и проверяются после каждой MDBG-операции.

В лог добавлены `original_protection`, `protect_rc`, `mdbg_write_rc`,
`restore_protection_rc`, `protection_restored`; backend записи —
`checked-mdbg+vm-protection`. Изменение относится только к однобайтовому
guard на FW 11.60. Существующие пути остальных прошивок сохранены.

Отбрасывание скачков 200–300 FPS, целое отображение до 120 FPS и
перезапись логов при активации сохранены. `/data/CommonFPS.log` и
`/data/CommonFPS_shellui.log` ограничены 64 КиБ каждый.

RC5 предназначена для аппаратной проверки исправления зафиксированного
отказа записи. Успешная сборка и host-тесты не подтверждают отображение
на самой консоли; FW 11.60 остаётся экспериментальной. Отдельное выключение,
воспроизводившееся без счётчика, этой сборке не приписывается.

## Установка вместо RC4

1. Заменить RC4 в действующей автозагрузке на
   `Common_FPS_PS5_v1.2.3_RC5.elf`, обновив имя в списке. Оставить один
   Common FPS; одновременно ELF и plugin не запускать.
2. Полностью перезагрузить консоль и использовать выбранный способ
   запуска со своим текущим набором остальных payload.
3. Запустить игру и подождать 20–30 секунд. В системном главном меню
   оверлей не создаётся; во время подготовки возможна `FPS: Loading`.
4. Если счётчик снова не появится, прислать новые `/data/CommonFPS.log`
   и `/data/CommonFPS_shellui.log` (если второй создан), а также название
   игры. Для диагностики дать сборке проработать в игре около минуты,
   чтобы лог успел записать результат запуска renderer.

ShellUI renderer встроен в основной ELF и отдельно не устанавливается.
