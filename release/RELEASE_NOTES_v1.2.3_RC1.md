# Common FPS for PS5 v1.2.3 RC1

Тестовая сборка для проверки на консоли.

**Дополнение после сообщения о KP в v1.2.1 на FW 11.60:** полную RC1 на этой
прошивке пока не запускать. Следующий шаг — отдельная диагностика
[FW1160 Preflight v0.1](FW1160_PREFLIGHT_v0.1_RU.md). В RC2 полный controller
на FW 11.60 временно заблокирован до аппаратной изоляции причины.

- Убраны значения 200–300 FPS из резервных DCE/HEN источников. Общий предел
  отображения — 120 FPS. Небольшой допуск измерения до 130 FPS ограничивается
  при отображении; значения выше допуска отбрасываются, а не превращаются в 120.
- Первый интервал DCE отбрасывается, как в проверенном VideoOut sampler.
  После перерыва длиннее трёх секунд или обратного хода времени измерение
  устанавливает новую базовую точку. При сбросе счётчика аномальная дельта
  не попадает на экран. Настоящее переполнение uint32 VideoOut поддерживается.
- Измерение времени переведено на монотонные часы.
- Для FW 11.60 разрешены проверка JIT-кода и существующая однобайтовая
  транзакция ShellUI через ptrace I/O. Адрес определяется по Mono-методу,
  исходные байты сверяются до записи, результат проверяется чтением.
- FW определяется через физическую версию SDK, с резервным sysctl: подмена
  `kern.sdk_version` не должна выбирать другой адаптер.
- Сохранено имя процесса `CommonFPS.elf` из v1.2.2.
- При каждой активации очищаются `/data/CommonFPS.log` и
  `/data/CommonFPS_shellui.log`. Каждый файл ограничен 64 КиБ; после заполнения
  новые записи не увеличивают его. Имена файлов больше не зависят от версии.

## Статус проверки

Host-регрессии проверяют VideoOut, фиксированный и адаптивный DCE, аномальные
значения HEN, паузы/смену времени, выбор адаптера 11.60, очистку лога и предел
размера при одновременных записях. Компиляция и проверки ELF/plugin выполняются
в PS5 Source Build.

FW 11.60 в этой сборке **экспериментальная**. Аппаратная проверка ещё не
выполнена. Работа предыдущей версии на FW 10.60 подтверждена пользователем;
новую сборку нужно проверить и на этой прошивке.

## Проверка на PS5

1. Удалить старую версию plugin из автозагрузки и перезагрузить консоль.
2. Установить только один вариант: ELF либо etaHEN plugin.
3. Проверить запуск PS4/PS5-игры, значения во время загрузки, переход между
   играми и восстановление после сна.
4. На FW 11.60 после теста сохранить `/data/CommonFPS.log` и
   `/data/CommonFPS_shellui.log`, включая случай, когда FPS не появился.
5. После повторной активации проверить, что логи содержат только новый запуск.

Файлы: `Common_FPS_PS5_v1.2.3.elf` и `Common_FPS_PS5_etaHEN_v1.2.3.plugin`.
