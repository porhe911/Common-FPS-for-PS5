# Common FPS for PS5 v1.2.0

Версия 1.2.0 — новая стабильная версия Common FPS с доработанным получением FPS,
восстановлением после lifecycle-событий и более компактным overlay.

## Изменения

- Реальный FPS в PS4 и PS5 играх.
- Подтверждена работа на FW 4.51.
- На FW 4.51 проверены 30 FPS и 60 FPS.
- Подтверждено восстановление FPS после Rest Mode.
- Подтверждена штатная перезагрузка после работы счётчика.
- Добавлен adaptive DCE fallback через `/dev/dce`.
- VideoOut остаётся предпочтительным источником FPS.
- После успешного DCE тяжёлый VideoOut discovery переходит в 60-секундный backoff.
- При повторных DCE misses recovery запускается автоматически.
- Обрабатывается смена game PID.
- Обрабатывается смена ShellUI PID.
- Standalone ELF и etaHEN plugin собираются из исходников.
- Размер шрифта overlay уменьшен с 26 до **24**.
- Публичные имена файлов упрощены.

## Статус системного ПО
