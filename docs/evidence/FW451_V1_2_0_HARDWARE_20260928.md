# Common FPS for PS5 v1.2.0 — FW 4.51 hardware evidence

**Date:** 28.09.2026

## Confirmed behavior

The current Common FPS implementation was tested on real PS5 hardware running
system software 4.51.

Confirmed:

- visible real FPS in a PS5 game;
- visible real FPS in a PS4 game;
- 30 FPS output;
- 60 FPS output;
- switching between game processes;
- ShellUI component startup;
- adaptive DCE fallback;
- Rest Mode → resume with FPS restored;
- normal reboot after the test sequence.

## Sampler evidence

On FW 4.51 the per-game VideoOut discovery did not validate a usable counter
for the tested processes, so the controller used the DCE fallback.

Observed successful sequence:

```text
DCE device online ...
DCE query online ...
DCE adaptive counter selected ...
Fallback sampler online backend=dce-adaptive ...
Sampler online ... first_fps=...
```

Different game processes produced 30 FPS and 60 FPS.

## ShellUI evidence

The ShellUI bootstrap and verified guard completed successfully before the
renderer became active:

```text
ShellUI bootstrap ... rc=0 ...
ShellUI hook request ... status=0 ... verified=1 ...
ShellUI renderer online ...
```

After a ShellUI PID change, the controller repeated the readiness/bootstrap
sequence and restored the overlay.

## Recovery

A temporary DCE query failure during a game transition did not leave the
counter permanently stuck. The controller woke the fallback/recovery path and
subsequent game processes returned valid FPS again.

## Result

FW 4.51 is considered **hardware confirmed** for Common FPS for PS5 v1.2.0
with PS4 and PS5 games, Rest Mode recovery and normal reboot behavior.
