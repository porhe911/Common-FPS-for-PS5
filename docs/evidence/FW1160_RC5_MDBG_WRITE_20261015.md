without READ/WRITE. VM protection setup and restoration succeeded, while
the selected MDBG writer returned 1 (the EPERM value). The log does not
separate raw MDBG syscall and reply status, so it does not prove which
level rejected writing. It also does not prove whether code was never
changed or was rolled back; the final state is original code/protection.
