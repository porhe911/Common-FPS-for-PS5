# FW 9.x (SDK 0x09050005): v1.2.4 user confirmation, 2026-11-20

In the previously reported failure, the user described a PS5 running
"прошивка 9.0", on which Common FPS v1.2.3 did not display FPS.
The diagnostics recorded firmware SDK `0x09050005` and
`fw_version: 0x9050005`.

The controller succeeded in FPS sampling (`first_fps=60`, DCE fallback).
The ShellUI probe selected `ptrace-io` and failed with
`status=-5 read_rc=14 read_fallback_rc=-1`; the renderer was
subsequently quarantined.

v1.2.4 extends the already existing FW 9.00 MDBG ShellUI code-read
and stopped one-byte guard path to the observed SDK 9.05 family and moves
both logs under `/data/CommonFPS/`.

After testing the source-built v1.2.4 candidate, the user stated:

> Вот теперь у меня счетчик fps появился и заработал.
> Можем публиковать его в github

This explicitly confirms the missing-overlay issue is resolved on the
affected console and approves publication. No new complete PS5 v1.2.4
runtime test matrix, Rest Mode confirmation, game-switching soak or
post-fix log pair was provided.
